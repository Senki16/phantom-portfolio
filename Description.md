A stylized interactive portfolio inspired by the visual identity of Persona 5, combining dynamic UI design, motion, and game-inspired aesthetics to showcase projects, skills, and creative development.

Built with a focus on immersive presentation, smooth animations, and modern web technologies.

## Features

- Persona 5 inspired UI/UX
- Interactive animated interface
- Project showcase section
- Skills and experience display

- Modern web development stack
